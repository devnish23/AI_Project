# Scripts Documentation

## fetchRedHatData.js
- Fetches Red Hat security advisories and stores them for later processing.
- Usage: `node scripts/fetchRedHatData.js`

## scrapeRedHatAdvisories.js
- Scrapes Red Hat advisories for CVE and patch information.
- Usage: `node scripts/scrapeRedHatAdvisories.js`

## scrapeRedHatRHEL.js
- Scrapes RHEL-specific data from Red Hat sources.
- Usage: `node scripts/scrapeRedHatRHEL.js`
